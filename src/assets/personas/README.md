# AI உதவியாளர் படங்கள்

ஆலோசனைப் பக்கத்தின் ஒவ்வொரு AI உதவியாளருக்கும் ஒரு படம். இந்தக் கோப்புறையில் கீழே உள்ள பெயரில் ஒரு
படத்தைச் சேர்த்து push செய்தால் போதும் — app தானாக அதை எடுத்துக்கொள்ளும்; நிரலில் எதையும் மாற்ற வேண்டாம்.
ஒரு உதவியாளருக்குப் படம் இல்லையெனில் `sample.webp` காட்டப்படும்.

| கோப்புப் பெயர் | உதவியாளர் | தலைப்பு |
|---|---|---|
| `general.webp` | ஜோதிட குரு | பொது ஆலோசனை, சொந்தக் கேள்வி |
| `marriage.webp` | மணவாழ்வு வழிகாட்டி | திருமணம், வாழ்க்கைத் துணை |
| `career.webp` | தொழில் வழிகாட்டி | வேலை, தொழில் |
| `wealth.webp` | செல்வ வழிகாட்டி | பணம், சேமிப்பு, கடன் |
| `health.webp` | நலம் வழிகாட்டி | ஆரோக்கியம் |
| `education.webp` | கல்வி வழிகாட்டி | கல்வி, தேர்வு |
| `children.webp` | சந்தான வழிகாட்டி | குழந்தை பாக்கியம் |
| `travel.webp` | பயண வழிகாட்டி | வெளிநாடு, இடமாற்றம் |

## படத்தின் விவரம்
- வடிவம்: **சதுரம்** (1:1); app அதை வட்டமாக வெட்டிக் காட்டும் — முகம்/உருவம் நடுவில் இருக்கட்டும்.
- அளவு: 512×512 முதல் 800×800 px வரை; கோப்பு **300 KB-க்குள்** (பெரிய கோப்பு app-ஐ மெதுவாக்கும்).
- கோப்பு வகை: `.webp` சிறந்தது; `.png`, `.jpg`, `.jpeg` உம் ஏற்கப்படும் (பெயர் அதேதான்: `career.png`).
- நடை: `sample.webp` போன்ற வரைபட நடை. உண்மை மனிதரின் புகைப்படம் போன்ற படங்களும் தெய்வப் படங்களும் வேண்டாம்
  (AI உதவியாளரை மனித ஜோதிடர் என்று காட்டக் கூடாது — Play Store விதி).
- பிறரின் படங்களை (மற்ற app-களின் படங்கள் உட்பட) பயன்படுத்த வேண்டாம்.

உதவியாளரின் பெயர், அறிமுகம், மாதிரிக் கேள்விகள்: `src/components/personas.js`.

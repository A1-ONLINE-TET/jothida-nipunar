## 2. உரிமையாளர் செய்ய வேண்டிய படிகள்

### அ. Firebase Console (project `jothidar-d1c8c`)
1. **Firestore → Rules:** repo-வின் `firestore.rules` கோப்பை ஒட்டி **Publish**. (புதிய `reports` விதி — புகார்களும்
   கருத்துகளும் தனித் தொகுப்பில் சேரும். வெளியிடும் வரை அவை அந்தந்தப் பயனரின் `users/{uid}` பதிவில் `reports`
   என்ற புலத்தில் சேமிக்கப்படும்; இழப்பு இல்லை.)
2. **Authentication → Sign-in method:** *Google* வழங்குநர் இயக்கத்தில் உள்ளதா பாருங்கள் (சோதனையில் Google உள்நுழைவுச்
   சாளரம் திறந்தது; ஏற்கனவே இயக்கத்தில் இருப்பதாகத் தெரிகிறது).
3. **Authentication → Settings → Authorized domains:** `jothida-nipunar.pages.dev` சேர்க்கவும் (சொந்த domain இருந்தால்
   அதையும்). இவை இரண்டும் முடிந்ததும் app-இன் கணக்குப் பக்கத்தில் "Google கணக்குடன் இணை" தானாகத் தோன்றும்;
   மறு வெளியீடு தேவையில்லை.
4. புகார்களைப் படிக்க: Firestore → `reports` தொகுப்பு (`kind` = `answer` அல்லது `feedback`).

### ஆ. Cloudflare
1. **அணுகல் குறியீட்டை நீக்குங்கள்** (வெளியீட்டுக்கு முன் கட்டாயம்): Pages → Settings → Environment variables →
   `VITE_REQUIRE_ACCESS` நீக்கு; Worker → Settings → Variables → `ACCESS_CODE` secret நீக்கு. குறியீடு இருந்தால்
   Play மதிப்பாய்வாளரும் பயனர்களும் உள்ளே நுழைய முடியாது.
2. AI செலவைக் கட்டுப்படுத்த, Worker-க்கு KV namespace ஒன்றை `RL` என்ற பெயரில் இணைத்தால் பயனருக்கு மணிக்கு 60
   அழைப்பு என்ற வரம்பு இயங்கும் (`worker/src/ratelimit.js`). இணைக்காவிட்டால் வரம்பு இல்லை.

### இ. Play Console
1. உருவாக்குநர் கணக்கு (ஒருமுறைக் கட்டணம் US$25), அடையாளச் சரிபார்ப்பு.
2. **Create app** → பெயர் `ஜோதிட நிபுணர் – தமிழ் ஜாதகம்`, மொழி Tamil (ta-IN), App, Free.
3. கீழே பகுதி 3–6-இல் உள்ள பதில்களை நிரப்புங்கள்.
4. **Testing → Closed testing:** `.aab` கோப்பைப் பதிவேற்றுங்கள். புதிய தனிநபர் கணக்குகளுக்கு, production-க்கு
   விண்ணப்பிக்கும் முன் குறைந்தது 12 சோதனையாளர்கள் 14 நாட்கள் தொடர்ந்து closed test-இல் இருக்க வேண்டும் என்ற விதி
   உள்ளது (Console-இல் தற்போதைய எண்ணிக்கையைப் பாருங்கள்).
5. **முதல் பதிவேற்றத்துக்குப் பின்:** Play Console → Setup → App signing → *App signing key certificate* → SHA-256
   மதிப்பை நகலெடுத்து `public/.well-known/assetlinks.json`-இன் `sha256_cert_fingerprints` பட்டியலில் சேர்த்து push
   செய்யுங்கள். இல்லையெனில் Play-இலிருந்து நிறுவிய app-இல் மேலே உலாவி முகவரிப் பட்டை தெரியும்.
6. ஒரு உண்மையான Android கைபேசியில் `.apk`-ஐ நிறுவிப் பாருங்கள் (முழுத்திரை, splash, நிறம்). இது இன்னும்
   எந்தச் சாதனத்திலும் ஓட்டிப் பார்க்கப்படவில்லை.

## 6. AI உள்ளடக்கக் கொள்கைக்கான நிலை

Play-இன் *AI-Generated Content* கொள்கை கோருபவை, நம் நிலை:

1. **app-க்குள் புகார்/கொடியிடும் வசதி** — உள்ளது. ஒவ்வொரு அரட்டைப் பதில், AI ஜோதிட பலன், AI தினப்பலன் ஆகியவற்றின் கீழ்
   "புகார் செய்"; காரணம் + விருப்பக் குறிப்புடன் Firestore-இல் சேரும்.
2. **தடைசெய்யப்பட்ட / தீங்கான உள்ளடக்கத்தைத் தடுத்தல்** — `worker/src/safety.js`:
   - தற்கொலை எண்ணம் → ஜாதகப் பதில் இல்லை; உதவி எண்கள் (Tele-MANAS 14416, 104, சினேகா 044-2464 0050, 112).
   - ஆயுள் / மரண காலக் கேள்வி → கணிப்பு மறுப்பு.
   - பிறக்கப்போகும் குழந்தையின் பாலினம் → மறுப்பு (PCPNDT சட்டம்).
   - "நீங்கள் மனிதரா?" → "AI உதவியாளர்" என்ற உண்மையான பதில்.
   - மருத்துவம், முதலீடு, சட்டம் சார்ந்த கேள்விகள் → பதிலுடன் எச்சரிக்கைக் குறிப்பு.
   - AI எழுதிய உரையில் மரண/ஆயுள்/பாலினக் கணிப்பு அல்லது "மருந்தை நிறுத்து" போன்றவை இருந்தால் அந்த உரை நிராகரிக்கப்படும்.
   - AI-க்கு அனுப்பும் ஒவ்வொரு prompt-இலும் இதே விதிகள் (`AI_GUARDRAILS`).
3. **சோதனை ஆவணம்** — `node scripts/test-safety.mjs`: 69 கேள்வி வகைப்பாட்டுச் சோதனைகள் (தடுக்க வேண்டியவை 47,
   தடுக்கக் கூடாதவை 22), 10 குறிப்புச் சோதனைகள், 12 AI-வெளியீட்டுச் சோதனைகள், 1 prompt விதிச் சோதனை. `npm test`-இன் ஒரு பகுதி.
4. **மனிதர் போல் நடிக்காமை** — ஆலோசனைப் பக்கம், அரட்டைத் தலைப்பு, முதல் செய்தி, மேல் அறிவிப்புப் பட்டை நான்கிலும்
   "AI உதவியாளர்; மனித ஜோதிடர் அல்ல".

**கட்டணம்:** தற்போது எல்லாம் இலவசம் (`PAYMENTS_ENABLED = false`). app-க்குள் டிஜிட்டல் சேவைக்குக் கட்டணம் வாங்க
விரும்பினால் Google Play Billing தேவை; இப்போதுள்ள Razorpay குறியீட்டை Android app-இல் அப்படியே இயக்கக் கூடாது.

## 6அ. கருத்து / புகார் → உரிமையாளரின் WhatsApp (விருப்பம்)

பயனர் செயலியில் அனுப்பும் கருத்து / புகார் Firestore `reports`-இல் பதிவாவதுடன், உரிமையாளரின் WhatsApp-க்கும் அறிவிப்பாக
வரும். உரிமையாளரின் எண் Worker ரகசியத்தில் மட்டும் இருப்பதால் பயனருக்குத் தெரியாது. இயக்கும் முறை:

1. CallMeBot-இன் அதிகாரபூர்வப் பக்கத்தில் (callmebot.com → "Free API WhatsApp messages") தற்போதைய எண்ணையும் அனுப்ப வேண்டிய
   வாசகத்தையும் பாருங்கள்; அந்த எண்ணைத் தொடர்புகளில் சேமித்து, உங்கள் WhatsApp-இலிருந்து அந்த வாசகத்தை அனுப்புங்கள்.
   பதிலாக ஒரு **API key** வரும்.
2. Cloudflare → Workers → `jothidarjothi` → Settings → Variables and Secrets → **Add** (வகை: Secret):
   - `WHATSAPP_PHONE` = நாட்டுக் குறியீட்டுடன் உங்கள் எண் (எ.கா. `919876543210`)
   - `CALLMEBOT_APIKEY` = வந்த சாவி
3. Deploy. செயலியின் கணக்கு → "கருத்து அல்லது புகார் அனுப்ப" வழியாக ஒரு சோதனைச் செய்தி அனுப்பிப் பாருங்கள்.

அனுப்பப்படுவது: கருத்து உரை + புகார் வகை மட்டும் (`worker/src/notify.js`). ரகசியங்கள் இல்லையெனில் எதுவும் அனுப்பப்படாது.

## 7. இன்னும் செய்யப்படாதவை

- **Push அறிவிப்புகள்** (தினப்பலன், சந்திராஷ்டமம், பண்டிகை நினைவூட்டல்): Android app அறிவிப்பு அனுமதியுடன் தயாராக
  உள்ளது; ஆனால் அனுப்பும் பகுதிக்கு Firebase Cloud Messaging சேவைக் கணக்கும், Worker-இல் நேர அட்டவணையும், சந்தாதாரர்
  பட்டியலுக்கான சேமிப்பும் தேவை. உரிமையாளர் Firebase-இல் சேவைக் கணக்கு விசையை உருவாக்கி Worker secret ஆக வைத்த
  பின் சேர்க்கலாம்.
- **ஜோதிடர் சரிபார்ப்பு:** பரிகார விதிகளையும் பலன் வாசகங்களையும் அனுபவமுள்ள ஒரு ஜோதிடர் பார்ப்பது நல்லது.
- **சாதனச் சோதனை:** Android app இன்னும் உண்மையான கைபேசியில் ஓட்டிப் பார்க்கப்படவில்லை.
- **தொடர்பு மின்னஞ்சல்:** தனியுரிமைக் கொள்கை "Play பக்கத்தில் உள்ள உருவாக்குநர் மின்னஞ்சல்" என்று குறிப்பிடுகிறது.
  குறிப்பிட்ட முகவரியைப் பக்கத்திலேயே அச்சிட விரும்பினால் `public/privacy.html`, `terms.html`, `delete-data.html`
  மூன்றிலும் "தொடர்பு" பகுதியை மாற்றுங்கள்.
